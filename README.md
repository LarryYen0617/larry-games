# Larry Games

Larry 的獨立瀏覽器遊戲網站。與法律學習網站使用不同儲存庫與發布路徑。

## 遊戲
### 霧鎮：月下審判
單人狼人邏輯推理，包含 24 關主線與自由調查模式。點選居民取得證詞、標記身分，再提交判定。
- 好人每句為真；狼人每句為假。
- 每案都有且只有一組解答。
- 推論檢查只使用已閱讀的證詞。
- 三階段提示、排除過程、星級與重玩。
- 瀏覽器保存進度，並支援 JSON 匯出／匯入。

所有故事、角色造型與介面均為本專案原創。不是官方凹嗚殺產品。
本作為單人邏輯謎題，並非多人即時狼人殺。

## 開啟
首頁：index.html
遊戲：mist-town/index.html
純靜態 HTML / CSS / JavaScript，不需要安裝套件或建置。
可使用一般靜態 HTTP 伺服器預覽；也能直接用瀏覽器開啟本機 HTML。

## 測試
安裝 Node.js 後執行：
```sh
node tests/game.test.cjs
```
涵蓋 24 關唯一解、排除過程、推論矛盾、完整互動流程、提示、評價、重玩與存檔資料驗證。
模擬流程測試不取代真實瀏覽器驗收。

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save。
不需要第三方金鑰。發布內容僅為此儲存庫的靜態網站。

## 存檔
進度僅存於瀏覽器，不上傳伺服器。更換網址、裝置或瀏覽器前先匯出。


## V3 自由調查與假設對照板
- 選擇 4 人／1 狼、6 人／2 狼、8 人／3 狼；案件碼範圍 1–999999。
- 同一難度與案件碼產生相同題目，可直接分享網址。
- 假設對照板保存一組標記，顯示與目前判斷的差異；還原可撤銷，不影響星級。
- 主線使用 mist-town-v1；自由調查以難度與案件碼隔離儲存。匯入需在相同模式與案件碼。
- 測試涵蓋 300 組隨機題唯一解、可重現性、假設還原、存檔隔離與重載。
